# E127 · DataVault Importer cho Tab Lý thuyết

## Mục tiêu

Bản E127 nâng Tab Dữ liệu thành cổng nhập nội dung Lý thuyết sống, dùng cho `lessons.json`.

## Những gì đã thêm

- `assets/datavault_importer/datavault-importer-E127.css`
- `assets/datavault_importer/datavault-importer-E127.js`
- `data/import_templates/bauman_math_theory_patch_template_E127.json`
- Link CSS/JS trong `subjects/math/index.html`

## Chức năng

1. Nhập file JSON cho Tab Lý thuyết.
2. Dán JSON trực tiếp.
3. Chọn chế độ:
   - `merge`: thêm lesson mới, thay lesson trùng `lessonId`.
   - `patch`: sửa từng phần lesson/slide theo `lessonId`, `slide.id` hoặc `role`.
   - `replace`: thay toàn bộ `DB.lessons` runtime.
4. Kiểm schema trước khi nhập.
5. Chặn nội dung PhD / Chương 41–56.
6. Chặn script/HTML injection, placeholder, `[object Object]`.
7. Lưu overlay trong trình duyệt bằng localStorage.
8. Rollback về bản trước lượt nhập gần nhất.
9. Xuất `lessons_E127_export.json` để giữ bản đã nhập.
10. Xóa overlay để quay về `lessons.json` gốc sau khi reload.

## Quy tắc an toàn

E127 chỉ tác động vào `DB.lessons` runtime và overlay localStorage. Không sửa trực tiếp các file khác trong ZIP khi người học đang dùng app.

Không đụng:

- `formulas.json`
- `exercises.json`
- `simulations.json`
- `question_bank.json`
- `mindmap.json`
- UI/core ngoài việc nạp adapter E127
